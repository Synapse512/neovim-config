### my neovim configuration
* features fuzzy finding, explorer window, file tabs, and workspaces 

## Plugin Keymaps

| Plugin | Keymap | Description |
| :--- | :--- | :--- |
| `fzf-lua` | `<leader>ff` | fzf files in directory |
| `fzf-lua` | `<leader>fc` | fzf C: |
| `fzf-lua` | `<leader>lg` | fzf live grep |
| `fzf-lua` | `<leader>fb` | fzf buffers |
| `fzf-lua` | `<leader>l` | fzf keymaps |
| `nvim-tree` | `<C-n>` | Toggle file explorer |
| `nvim-tree` | `<leader>e` | Focus file explorer |
| `workspaces.nvim` | `<leader>aw` | Add workspace |
| `workspaces.nvim` | `<leader>ow` | Open workspace |
